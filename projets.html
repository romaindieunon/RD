Deux projets concrets que j'ai menés de bout en bout : conception, déploiement, configuration, tests et documentation. Ils illustrent mes compétences en administration des systèmes et en sécurité réseau.

1 Active Directory, DNS & DHCP

Déploiement d'une infrastructure Active Directory complète avec deux contrôleurs de domaine, basculement DHCP, zones DNS, OU, utilisateurs, GPO et déploiement de l'agent GLPI.

Domainebtssio.rd
Contrôleurs2 DC (Beta + Delta)
Haute dispo.DHCP Hot Standby
OSWindows Server 2022
HyperviseurProxmox VE
Captures154 étapes documentées

Périmètre

  • Active Directory Domain Services : forêt et domaine racine, niveaux fonctionnels Windows Server 2016, mot de passe DSRM.
  • DNS : zones directe et inversées (200.168.192.in-addr.arpa et 201.168.192.in-addr.arpa), enregistrements PTR pour serveurs et clients.
  • DHCP : étendue 192.168.201.0/24, exclusion d'IP pour la borne Wi-Fi, réservation par MAC, basculement Hot Standby Beta ↔ Delta.
  • OU, utilisateurs, groupes : modèle AGDLP (Account → Global → Domain Local → Permission), groupes GDL pour gérer les permissions des partages élèves/formateurs.
  • GPO : sécurité du domaine (mots de passe ANSSI, verrouillage de session, audit), restrictions utilisateurs (Panneau de configuration, CMD, PowerShell), durcissement ordinateurs (pare-feu, Windows Update, blocage USB), déploiement automatique de l'agent GLPI via MSI + clé de registre.

Compétences mobilisées

Windows Server 2022 Active Directory DNS DHCP GPO Proxmox VE PowerShell GLPI

Bilan

Infrastructure résiliente testée en production : authentification AD opérationnelle, DHCP redondant (basculement Beta → Delta validé), résolution DNS bidirectionnelle, agent GLPI déployé automatiquement sur les postes joints au domaine. Documentation complète rédigée pas à pas (154 captures) pour permettre la reprise par un autre administrateur.

2 PFsense (Pare-feu & VLAN)

Installation et configuration de deux pare-feu PFsense redondés (Alpha & Lambda) en haute disponibilité CARP, avec VLAN, IDS Snort, DHCP Relay et sauvegarde XML.

SystèmePFsense (FreeBSD)
Pare-feu2 nœuds (Alpha + Lambda)
Haute dispo.Cluster CARP + XMLRPC
VLAN200 (serveur), 201 (client)
IDS / IPSSnort
Captures61 étapes documentées

Périmètre

  • Installation PFsense : ISO, partition UFS, configuration WAN/LAN par la console, durcissement (HTTPS forcé, SSH, mot de passe administrateur fort).
  • VLAN : VLAN 200 (serveurs, 192.168.200.0/24) et VLAN 201 (clients, 192.168.201.0/24), trunks 802.1Q vers le switch Cisco.
  • Routage inter-VLAN assuré par PFsense, avec règles de pare-feu spécifiques par sous-réseau.
  • DHCP Relay pour transmettre les requêtes DHCP des clients (VLAN 201) vers les contrôleurs AD du VLAN 200.
  • IDS/IPS Snort : installation, configuration, oinkcode, mise à jour des règles officielles, alerting des intrusions.
  • Cluster CARP : VIP partagées (LAN, VLAN 200, VLAN 201), NAT Outbound Hybride, synchronisation XMLRPC entre Alpha (maître) et Lambda (secours).
  • Sauvegarde : export régulier de la configuration en XML pour restauration rapide.

Compétences mobilisées

PFsense FreeBSD VLAN 802.1Q CARP / VRRP NAT Snort Switch Cisco DHCP Relay

Bilan

Infrastructure réseau sécurisée et résiliente : un client du VLAN 201 sort sur Internet via le NAT d'Alpha, Lambda reprend l'IP virtuelle CARP en quelques secondes lorsque Alpha est éteinte, la synchronisation XMLRPC propage en temps réel toute modification de configuration entre les deux nœuds, et Snort détecte effectivement les tentatives d'intrusion simulées.
